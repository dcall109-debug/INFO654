First listen / My starting pick

Start with Passionfruit.

If you only try one song from this page, I’d start with “Passionfruit.” The beat is laid-back, but it still has enough movement to keep your attention. It’s an easy song to put on while hanging out or getting ready to go somewhere.

From there, try “Break from Toronto” if you want to stay with something smooth, or “Your Friends” if you want more of a rap and singing mix.
